# data/

Put the PDF documents of your knowledge base in `data/documents/` when running locally.
In Google Colab, the notebook stores uploaded files in the same folder (inside the temporary VM).

**Do not commit PDFs.** `.gitignore` excludes them: they may be copyrighted or private.
The example evaluation questions in `evaluation/eval_questions.json` refer to the course guide `RAG_Detailed.pdf`.
